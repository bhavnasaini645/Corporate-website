# Multi-Page Corporate Website

## 📌 Project Overview
This project is a modern and responsive multi-page corporate website developed using HTML, CSS, and JavaScript. The website is designed to represent a professional company online with multiple sections and smooth navigation.

## 🚀 Features
- Responsive Design
- Multi-Page Navigation
- Modern User Interface
- About Us Section
- Services Section
- Team Section
- Contact Form
- Mobile-Friendly Layout
- Smooth Hover Effects
- Clean and Professional Design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Pages Included
1. Home Page
2. About Us
3. Services
4. Team
5. Contact Us

## 📁 Project Structure
```
corporate-website/
│
├── index.html
├── about.html
├── services.html
├── team.html
├── contact.html
│
├── css/
│   └── style.css
│
└── js/
    └── script.js
```

## 💻 How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
